# Default skill: news

## Workflow

- Search dated primary sources and cross-check important factual claims.
- Distinguish publication date, event date, confirmed facts and uncertainty.
- Create a concise sourced report in the requested language; verify the output file and never invent citations.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
