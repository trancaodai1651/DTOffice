# Default skill: video

## Workflow

- Plan a hook, story, shot list, captions and platform format.
- Use licensed footage or clearly labelled original graphics and preserve user originals.
- Render with the provided tools and verify the actual MP4; never mark an absent or broken video as finished.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
