# Short Video Reels

Default to Vietnamese output. Use this skill to turn an idea into a vertical video script or creative direction.

## Workflow

1. Define viewer promise in one sentence.
2. Choose format: talking head, POV, story, tutorial, comparison, before/after, reaction, list, photo carousel, or product-in-use.
3. Write 3-5 hook options for the first 3 seconds.
4. Build the beat sheet:
   - hook
   - context
   - tension/value
   - proof/example
   - CTA
5. Add shot list, on-screen text, voiceover/dialogue, sound/edit rhythm, caption, and CTA.
6. Add safety review for sensitive topics.

Read `references/short-video-template.md` for templates and `references/platform-notes.md` for Facebook/TikTok differences.

## Defaults

- Put the strongest visual or sentence first.
- Keep one core message per video.
- Show concrete detail instead of explaining too much.
- For Reels or ads, make product/brand visible inside a real situation.
- For organic TikTok, prioritize watch completion, rewatch, share/save reason, and follow promise.

## Output Template

## Recommended script
## Shot list
| Time | Visual | Text overlay | Audio/edit |
