# Default skill: devops

## Workflow

- Verify versions, reproducible builds, runtime dependencies and CI configuration.
- Check packaged artifacts, checksums and rollback/update compatibility.
- Never push, publish or deploy unless the user goal explicitly authorizes it.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
