# Default skill: ai

## Workflow

- Define the agent input, tool permissions, output contract and evaluation criteria.
- Bound context and retries, preserve user intent and keep secrets out of prompts and logs.
- Test tool behavior with fixtures before paid inference; disclose what was actually evaluated.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
