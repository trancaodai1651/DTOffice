# Default skill: app

## Workflow

- Keep Windows and macOS resources, lifecycle and packaging compatible.
- Handle local server startup, shutdown, file paths and missing tools clearly.
- Verify the bundled runtime and avoid stopping unrelated user processes.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
