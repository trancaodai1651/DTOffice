# Default skill: qa

## Workflow

- Derive checks from acceptance criteria and reproduce failures before changing tests.
- Exercise negative cases, platform differences, lifecycle and regressions.
- Report exact commands, results, skipped tests and unresolved issues; end verification with VERDICT: PASS or FAIL.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
