# Default skill: architect

## Workflow

- Trace actual entry points and existing module boundaries before proposing changes.
- Specify interfaces, data flow, failure handling and migration steps.
- Choose the smallest compatible design and name the exact files affected.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
