# Default skill: security

## Workflow

- Review auth boundaries, untrusted inputs, file paths and credential handling.
- Check dependencies and access to processes, network and local files.
- Document concrete impact and mitigations without printing secrets; verify fixes.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
