# Default skill: uiux

## Workflow

- Design the user journey and empty, loading, error and success states.
- Include keyboard use, focus order, accessible labels and responsive behavior.
- Reuse existing components and document observable acceptance criteria.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
