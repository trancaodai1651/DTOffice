# Default skill: database

## Workflow

- Review schema, indexes, migrations, transactional boundaries and data invariants.
- Preserve existing data and plan backups and rollback before destructive operations.
- Test migration and failure recovery with disposable data.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
