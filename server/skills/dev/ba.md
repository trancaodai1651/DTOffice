# Default skill: ba

## Workflow

- Map actors, user stories, business rules and edge cases.
- Specify required inputs, state changes, invalid cases and permission boundaries.
- Leave an implementable requirements checklist tied to acceptance criteria.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
