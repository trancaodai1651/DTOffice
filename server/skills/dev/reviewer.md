# Default skill: reviewer

## Workflow

- Review the diff and its call sites for correctness and maintainability.
- Check state transitions, compatibility, error handling and unnecessary scope.
- Cite concrete files and actionable defects; give VERDICT: PASS or FAIL based on evidence.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
