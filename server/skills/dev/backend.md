# Default skill: backend

## Workflow

- Validate inputs and authorization at the server boundary.
- Preserve existing API/data compatibility; handle retries and errors explicitly.
- Test success, invalid inputs, concurrency and failure paths without using real credentials.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
