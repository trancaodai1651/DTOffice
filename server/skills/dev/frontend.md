# Default skill: frontend

## Workflow

- Trace component markup, DOM IDs, state ownership and server contracts.
- Implement responsive and accessible UI with both supported languages.
- Verify the changed flow in a browser and check console errors and resource cleanup.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
