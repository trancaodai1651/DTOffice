# Default skill: strategist

## Workflow

- Define positioning, personas, journey, channels and conversion objectives.
- Link each channel and content format to a measurable audience need.
- Produce a phased plan with assumptions, dependencies and measurement.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
