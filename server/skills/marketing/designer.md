# Default skill: designer

## Workflow

- Read the brief, brand rules and source asset licenses.
- Create platform-appropriate layouts with legible typography, hierarchy and safe margins.
- Export correctly sized assets and include editable sources where possible.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
