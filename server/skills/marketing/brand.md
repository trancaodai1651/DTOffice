# Default skill: brand

## Workflow

- Extract the existing brand voice, proof points and visual constraints.
- Create consistent messages, vocabulary and do/dont examples.
- Review assets against the same brand promise without inventing endorsements.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
