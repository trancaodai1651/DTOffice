# Default skill: events

## Workflow

- Define audience, event outcome, agenda, logistics and owner checklist.
- Plan registration, accessibility, contingencies and post-event measurement.
- Prepare vendor/budget options without booking or spending money.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
