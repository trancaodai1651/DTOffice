# Default skill: email

## Workflow

- Segment by consent and audience need, then define one purpose per email.
- Write subject, preview text, body and CTA with clear opt-out guidance.
- Prepare a testable sequence; do not send emails without explicit authorization.

## Handoff

Deliver the requested files and a short report: decisions, evidence, checks actually run, remaining risks and next owner. Update the project handoff as its instructions require. Do not claim training, testing or execution that did not occur.
