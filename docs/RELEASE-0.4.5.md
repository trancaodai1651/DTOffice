# DT Office 0.4.5

- DT Office branding across the desktop window, web UI, IDE panel and Vietnamese/English text.
- New English and Vietnamese documentation, with source, support and downloads in DTOffice.
- Windows x64 installer and macOS Universal app for Intel and Apple Silicon, including Node.js.
- Claude Code and Codex integration, CLI/model/effort selection, and a 15-role AI team with separate sessions.
- Shared project context through INDEX, STATE and durable MEMORY files.
- A fresh repository history for the current DT Office source snapshot.

Download the Windows `-setup.exe` or macOS `_universal.dmg`. The `.app.tar.gz` contains the same Mac application. Verify downloads using `SHA256SUMS.txt`.

The macOS app is ad-hoc signed and is not notarized. Windows installers are unsigned. Existing app data stays in `~/.my-office`. AI services require a separate account login.

The MIT copyright and permission notices remain included in the source and packaged app.
